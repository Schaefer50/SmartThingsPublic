# Printable PDF products for Etsy

`build_planner.py` generates the **Undated Life & Budget Planner**, a 17-page printable bundle, in three color themes. Each theme comes in US Letter and A4 and includes ready-to-upload Etsy listing photos.

```bash
pip install reportlab pymupdf pillow
python3 pdf-products/build_planner.py                          # everything
python3 pdf-products/build_planner.py --theme sage --size a4   # just one
```

Output:

```
output/Life-Budget-Planner_<theme>_LETTER.pdf   ← upload to Etsy as the digital files
output/Life-Budget-Planner_<theme>_A4.pdf
output/listing-photos/<theme>/01-hero.jpg …     ← listing photos (2700×2025)
```

Before publishing, set `SHOP` at the top of `build_planner.py` to your Etsy shop name and rebuild. It appears in each page footer and in the PDF metadata.

See **[ETSY_LISTING.md](ETSY_LISTING.md)** for the title, tags, description, and pricing.

## Customizing

- **New color theme:** add an entry to `THEMES`.
- **Add or remove pages:** edit the `pages` list in `Planner.build()`. Contents links and PDF bookmarks update automatically.
- **New page type:** write a method using the `header`, `section`, `table`, `checklist`, and `rules` helpers.
